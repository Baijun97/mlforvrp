# Benchmark sources

Source repository: https://github.com/PyVRP/Instances

This collection contains all 56 Solomon instances and all 60 Gehring–Homberger 200-customer instances, each paired with its source reference solution. The supplied split manifest assigns these 116 instances to 92 training, 12 validation and 12 test instances. The recorded route-construction experiments use the 12 validation and 12 test instances.

These benchmark files are third-party data, not generated by this project. The accompanying .sol files are reference solutions, not outputs from the XGBRanker constructor.
