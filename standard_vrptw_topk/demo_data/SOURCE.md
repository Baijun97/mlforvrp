# Benchmark sources

Source repository: https://github.com/PyVRP/Instances

This subset contains the 24 standard VRPTW validation and test instances with at most 200 customers used in this experiment, with their source reference solutions. It includes instances from the Solomon and GH200 directories.

These benchmark files are third-party data, not generated by this project. The accompanying .sol files are reference solutions, not outputs from the XGBRanker constructor.
